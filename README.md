# 🚀 API Testing Portfolio (Manual & Postman)

Este repositório contém um projeto focado em **Testes Manuais de API**, projetado para demonstrar habilidades em validação de *endpoints*, estruturação de testes de backend e documentação.

## 🎯 Objetivo
Demonstrar competências técnicas na validação de APIs RESTful, incluindo:
- Validação de Status Codes (200, 201, 400, 401, 403, 404, 500)
- Criação e execução de testes de CRUD (GET, POST, PUT, DELETE)
- Análise de Payload (JSON) e validação de contratos
- Testes de autenticação baseada em tokens (Bearer/Auth/Cookies)
- Elaboração de relatórios de Bugs para Backend

## 🛠️ Ferramentas e Tecnologias
- **Postman** (Execução e organização das requisições)
- **Restful-Booker API** (API de testes pública utilizada como base)
- **Markdown** (Documentação e relatórios)

## 📂 Estrutura do Projeto
- `/test-plan` → Estratégia e planejamento dos testes da API.
- `/test-cases` → Casos de teste detalhados por endpoint.
- `/postman-collection` → Contém a Collection do Postman (arquivos `.json`) exportada para facilitar a reprodução dos testes.
- `/bug-reports` → Documentação de falhas encontradas durante os testes da API.

## 📈 Diferencial Técnico
Com anos de experiência lidando com banco de dados (Oracle/SQL) e análise de logs no mercado financeiro, a camada de backend é onde tenho grande facilidade de atuar. Este projeto reforça minha capacidade de não apenas olhar a interface, mas investigar o tráfego de dados, analisar respostas do servidor e validar regras de negócio "por baixo do capô".
